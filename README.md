# TANK DUEL

スマホ・タブレットの**ウェブブラウザ**で遊べる、二人対戦の戦車ゲームです。**1台の画面を二人で使います。キーボードは不要です。**

## 遊び方

1. [ゲームをブラウザで開きます](https://adash333.github.io/tank-duel/)。端末を二人の間に置いて向かい合ってください。
2. 「対戦をはじめる」をタッチします。
3. 上側（向こう側）の緑色パネルが1P、下側（手前側）のオレンジ色パネルが2Pです。1Pの操作パネルは180度回転し、向こう側から文字が読めます。
4. 移動パッドをドラッグすると、その方向へ戦車が向いて移動します。指を離すと停止します。
5. 砲撃ボタンをタッチすると、戦車が向いている方向に発射します。長押しで連射できます。

二人が同時に移動・砲撃できます。戦車は1Pが上側、2Pが下側から互いに向かって開始します。両者とも指を動かした方向に戦車が移動し、上側パネルの移動パッドも指の動きに追従します。

最初から対面プレイ画面が開きます。戦場下の「⛶」で設定画面を開いて戦場を選び、もう一度押すと対面プレイ画面に戻ります。スマホ・タブレットの縦向き・横向きに対応しています。

## ルール

- 3ラウンド先取で勝利。
- 戦車の耐久力は3発分。先に相手を撃破するとラウンド勝利。
- 1ラウンドは60秒。時間切れは残り耐久力で判定し、同じなら引き分け。
- 同時撃破も引き分け。引き分けは得点されず、次のラウンドに進みます。
- レンガは2発で破壊できます。金属壁と戦場の外壁では弾が1回反射し、次に反射面へ当たると消えます。
- 砲撃は約0.55秒ごと。自分の弾は自分の戦車には当たりません。
- 戦場は「補給基地」「交差戦線」「中庭」の3種類。
- 一時停止、リセット、再戦、効果音ON/OFFに対応。画面を離れると自動で一時停止します。

## 起動

外部ライブラリ、アカウント登録、データベースは不要です。

```sh
npm start
```

PCでは `http://localhost:3000` を開きます。同じWi-Fiのスマホ・タブレットからは `http://PCのLAN内IPアドレス:3000` を開いてください。PCのファイアウォールで必要に応じてこの接続を許可します。

Node.js 22以上を使用してください。依存パッケージのインストールは不要です。PC上では `index.html` を直接開いても動きますが、スマホ・タブレットにはHTTP/HTTPSで配信してください。

## ブラウザに公開する（GitHub Pages）

このリポジトリの **Settings → Pages → Build and deployment** で、**Deploy from a branch → main → / (root)** を指定して保存します。公開先は通常 `https://<GitHubユーザー名>.github.io/tank-duel/` です。

GitHub Pagesは公開リポジトリで利用できます。非公開リポジトリは対応プランが必要です。Pagesを有効化した後、画面に表示される実際の公開URLを確認してください。

ほかの静的ホスティングサービスを使う場合は、`npm run build` が生成する `dist/` を配置します。

## 検証

```sh
npm test
npm run build
```

対戦ロジックの12項目を検証します：二人の同時移動・砲撃、タッチ方向の照準、障害物・戦車との衝突、レンガ破壊、反射、撃破、3本先取、同時撃破、時間切れ、カウントダウン、ラウンド移行。

初版はChromiumのモバイルエミュレーションで、390×844（スマホ縦）、844×390（スマホ横）、1024×768（タブレット）を確認しました。4点同時タッチ、指を離した時の停止、停止・再開、リセット、戦場切替も検証しています。

対面版では全3戦場の上下から向かい合う開始位置と、二人の同時移動・砲撃を含む12項目の対戦テストが通りました。対面版のブラウザ再検証は、実行環境の権限制限でChromiumを起動できず未完了です。実機のiOS Safari・Android Chromeでの操作確認も未実施です。

## ファイル

- `index.html`：画面とタッチ操作パネル
- `styles.css`：スマホ・タブレット・横向き表示
- `src/engine.js`：描画から独立した対戦ルール
- `src/game.js`：タッチ入力、Canvas描画、効果音
- `test/engine.test.js`：対戦ロジックのテスト
- `scripts/serve.js`：依存ライブラリ不要のHTTPサーバー
- `scripts/build.js`：静的配信用ファイルの生成

オンライン通信対戦ではなく、同じ端末での対戦です。PCではWASD＋Space（代替F）、矢印キー＋Enter（代替右Shift）の補助操作も利用できます。
