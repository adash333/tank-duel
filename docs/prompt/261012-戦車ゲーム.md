## 依頼1：二人対戦の戦車ゲームと新しいリポジトリ

### プロンプト本文

```text
戦車で対戦するゲームが作りたいです。二人で対戦できるようにしてください。 新しいGitHubリポジトリを作り、でそこでやりたいです。
```

### 結果

- ゲーム名を「TANK DUEL」とし、ブラウザで動くHTML・CSS・JavaScriptの戦車ゲームを作成した。
- 移動、砲撃、3発分の耐久力、3ラウンド先取、60秒のラウンド制限、引き分け、障害物、レンガ破壊、1回反射する弾、3種類の戦場を実装した。
- 効果音、一時停止・再開、リセット、再戦、画面を離れた場合の自動停止を実装した。
- `src/engine.js` に対戦ルール、`src/game.js` に入力・描画・音声処理を分け、12項目の対戦テストと静的配信用のビルドを用意した。
- 新規リポジトリの作成は接続アプリの権限不足で実行できず、ユーザーに空のリポジトリの作成を依頼した。完成したソースはその後 `adash333/tank-duel` のmainに保存した。

## 依頼7：向かい合って対戦する画面

### プロンプト本文

```text
プレイヤー1と2が向かい合って対戦できるように画面を設定してください。
```

### 結果

- 1Pの操作パネルを上側、2Pの操作パネルを下側に置く対面用レイアウトへ変更した。
- 1Pのパネルを180度回転させ、上側から文字・耐久力・勝利数を読めるようにした。残り時間も両側から読める表示にした。
- 回転したパネルでも、移動パッドのつまみが指の物理的な動きに追従するように調整した。戦車は指を動かした方向へ進む。
- 戦車の開始位置を上中央の1Pと下中央の2Pに変更し、互いに向かう初期角度とした。全3戦場の開始位置が障害物に重ならないことを確認した。
- 最初から対面プレイ画面を開くようにし、「⛶」で設定画面に切り替えられるようにした。
- 更新後の対戦テスト12項目とビルドは成功。横向きの画面の寸法を静的に確認し、上下の操作パネルと戦場が収まるよう余白を調整した。
- ブラウザによる再検証は、実行環境の権限制限でChromiumが `setsockopt: Operation not permitted` により起動できず、未完了。実機のiOS Safari・Android Chromeも未検証。
- 変更をmainのコミット `4afbda721c772d6606d50f34194af71d6c41acce` に保存し、対応するGitHub Pagesのbuild・deployジョブが成功したことを確認した。

## 依頼8：/save-prompt スキルの保存・実行と自動化

### プロンプト本文

```text
スキル　/save-prompt として、以下の内容を保存して、実行してください。また、基本的に、毎回、自動で/save-promptを実行してほしいです
docs/prompt/ フォルダに、上の　「プロンプト本文」（そのまま）　と　その結果の内容をまとめたものを　YYMMDD-(複数あれば連番 01 など)-題名.md という名前で保存します。同日のmdファイルと一連の流れでまとめられる内容は、一つのmdファイルにまとめるようにしてください。さらに、 それまでのすべての変更をgit addしてmainにpushすることを、　スキル　/save-prompt として保存して下さい
```

### 結果

- `.agents/skills/save-prompt/SKILL.md` に `/save-prompt` の手順を保存した。原文を改変しないこと、結果を分けて記録すること、同日の関連作業をまとめること、ファイル名と連番、全変更のステージングとmainへの反映を定義した。
- `AGENTS.md` に、このリポジトリでは毎回の対応終了前にスキルを自動実行する継続指示を保存した。別のプロジェクトやアカウント全体の設定を変更したものではない。
